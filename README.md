# Aesthetic Edge Design

🌿 **Aesthetic Edge Design**  
[Live Website »](https://aestheticedgedesign.com/)

Aesthetic Edge Design is a creative studio offering high-end **Interior**, **Exterior**, **Landscape**, and **3D Animation** design services. This project delivers a premium, responsive website experience to showcase the company’s stunning visuals and unique design concepts.

---

## ✨ Features

- 🏠 Elegant and Minimal Homepage Layout
- 🖼️ Dynamic Portfolio Gallery
- 🪴 Service Sections (Interior, Exterior, Landscape, Animation)
- 📱 Fully Responsive Design (Mobile First)
- 💬 Contact Form Integration
- 🔐 Admin Panel with CMS (Powered by Yii2)
- ⚙️ Performance Optimized for Fast Load Times

---

## 🛠️ Tech Stack

| Frontend           | Backend              | CMS               | Deployment              |
| ------------------ | -------------------- | ----------------- | ----------------------- |
| React.js (Next.js) | Yii2 (PHP Framework) | Custom-built CMS  | Hosted on Custom Server |
| Style Component    | REST API Integration | Admin Auth System | SEO Optimized           |
